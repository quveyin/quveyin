**Bireysel bitirme projem · Kayıp hayvan eşleştirme**

`Ruby on Rails` `Active Record` `PostgreSQL` `HTML / CSS`

`Ruby` `Ruby on Rails` `Oyun mantığı` `Web arayüzü`
